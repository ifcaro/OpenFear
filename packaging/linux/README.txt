OpenFear (Linux)

You need your own legally-owned copy of Atmosfear (CD-ROM, ISO, or an
already-installed copy) to play. OpenFear does not include the original
game's assets.

To install game assets, run once:
  ./openfear --assets <path-to-your-Atmosfear-CD-or-ISO-or-folder> --install

Then run ./openfear to play.

To uninstall game assets, run:
  ./openfear --uninstall
