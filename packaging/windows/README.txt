OpenFear (Windows)

You need your own legally-owned copy of Atmosfear (CD-ROM, ISO, or an
already-installed copy) to play. OpenFear does not include the original
game's assets.

To install game assets: double-click Install.bat (it auto-detects a
mounted CD/ISO), or drag your Atmosfear folder/CD/.iso onto Install.bat
to install from that source directly.

Then run openfear.exe to play.

To uninstall game assets: double-click Uninstall.bat.
